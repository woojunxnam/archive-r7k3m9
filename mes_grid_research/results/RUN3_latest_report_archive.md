## 1. FQ 회계 / 불변식 감사 — PASS
- 엔진 `audit=True`: 매 bar마다 lane 수량 = tranche 합, 총수량 = lane 합, capacity ≤ 32, cost-sum drift 0, 열린 tranche = 닫힌 + 보유, 사라진/중복 tranche 없음. 후보 3개(FQ_12_20, FQ_16_16, FQ_16_16_add) × **713,842 bar 전부 통과**.
- FQ_16_16_add: 진입 7,193 = 청산 7,186 + 보유 7. realized = Σ(exit−entry)×qty×$5 − commission − roll 비용과의 차이 ~5e-8 달러.
- Negative control(슬롯 몰래 반납, basis reset)은 모두 예외 발생 → 감사가 실제로 오류를 잡는다.
- 원장 감사: 2022-08~10 최악 구간, 2025-02~06, 고빈도 월(2025-10 / 2021-03)의 fills / closed trades / inventory CSV 저장.
- **"recycle lane 가득 참 ≈0%"의 이유**: 2022에 recycle tranche 12–15개가 수백 일 갇혀 있고(최장 766일), 남은 1–4 슬롯만 TP +2로 회전(2022-08~10: 매수 157 / 매도 152). 16/16이 모두 차는 순간은 0.17%(FQ_12_20은 0%). 오류가 아니라 실제 구조 — "활동"의 상당 부분이 소수 슬롯의 회전이다.
- recycle 청산 승률 100%는 손실 tranche를 닫지 않기 때문(미실현으로 남음). 성공 지표로 쓰면 안 된다.

## 10. 살아남은 것
- 회계: FQ 수익은 회계 오류가 아니다(불변식·원장·roll 정산 모두 통과).
- 손익 edge: 슬리피지 2–4틱, TP 2.5–5에서 −5~−12%로 유지. YM cross-market에서도 같은 순서·비슷한 비율.
- 작은 한도(C10, C14)의 깊이: fresh 최소 equity $76–97k가 2–3틱에서도 유지.
- 보수적 limit recycle 진입(C14_lmt, C32_lmt): 비용 감소, 활동 유지, C32의 슬리피지 민감도 완화.
- 이익 layer 전체 수확(E, harv5): C32 깊이를 줄이는 유일한 청산 모듈(손익 희생 큼).
- Recycle 진입 필터(bs70, rpos60): 무진입을 짧게 유지하며 fresh 깊이 개선 — 단 recycle은 사실상 꺼지고 "core 중심 grid + 희소 recycle" 구조가 된다.

## 11. 실패한 것
- 목표("FQ 활동 유지 + fresh 깊이 대폭 감소")는 **달성하지 못했다.** 활동(무진입 ≤10일, recycle 3회/일)을 유지하는 모든 후보의 최악 fresh 최소 equity는 $23–54k.
- Bottom 예측: 약 150개 이벤트 정의의 최고 lift +1.7pp, 확인 신호는 오히려 −1.5~−3.5pp, BottomScore ≥70 +2.4–2.7pp(2025–26 +0.4pp), chronological ML AUC 0.50–0.51 → **신뢰할 만한 bottom edge 없음.** FQ 수익은 bottom picking이 아니라 재고 구조 + ES 상승 drift에서 온다고 판단.
- Recycle 실패 진단: 실패 9.46% (평균 MAE 138.6pt vs 성공 6.2pt). 1d/5d 범위 상단, 낮은 변동성, 늦은 시간대에서 더 많지만 이 차이로 만든 필터는 활동을 줄여서만 도움이 됐다.
- LIFO recycle 청산(B/C), 이익 recycle만 수확(D), HIGH/CRITICAL 부분 청산(F): 무효과 또는 악화.
- 계좌 DD core pause 계열 전부 무효과; all-pause / equity cap은 거래 중단(298–758일)으로만 작동.
- Cooldown, 동적 TP(vol/ATR/late/inv), core 필터, momentum governor, vol cap: 노이즈 수준이거나 악화.
- 진짜 OOS / MES: 데이터 부재로 미수행.

## 12. RUN-4 권고 (정확히)
1. **진짜 OOS 우선**: 2026-05-28 이후 ES 1분(또는 MES 1분) 데이터를 확보해 `FROZEN_CANDIDATES.json` + `FROZEN_POSTHOC_FILTERS.json` 후보를 **재조정 없이 1회** 실행. 데이터 없이는 새 로직 탐색을 늘리지 않는다.
2. **MES 체결 검증**: MES 1분(가능하면 tick/1초) 데이터로 limit_close recycle 진입의 체결률·queue·부분체결을 측정. C32는 2–3틱에서 fresh 깊이가 무너지므로 체결 품질 확인 전에는 C32 계열을 후보에서 보류.
3. **구조 재정의 실험(사전 등록, 소규모)**: 결과상 수익원은 core 재고 + drift이고 recycle은 슬롯 회전 도구다. RUN-4는 "core 한도 × recycle 슬롯 수 × recycle 진입 필터 강도" 3축만 소규모 격자(≤30 configs)로, 2019–2021 선택 / 2022–2026 확인으로 분리해 재검증한다(2022–2026 결과를 선택에 쓰지 않음).
4. **자본 등급별 권고 틀 유지**: $150k에서 최악 fresh ≥$90k를 원하면 C10 또는 C14_rpos60(단, recycle 거의 없음), ≥$75k면 C14_lmt, 활동 우선이면 C32_lmt지만 최소 $300k 이상의 자본이 필요하다는 표현으로 보고. 단일 임계값·합성 점수는 쓰지 않는다.
5. **보고 필수 항목 추가**: recycle 거래/일과 recycle P&L을 "활동"의 정의에 포함(무진입일만으로는 필터 후보의 활동 소멸이 가려진다).
