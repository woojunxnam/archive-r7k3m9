# PH7 POSITION MANAGEMENT WITH MATCHED CONTROLS — preregistration (alone)

Eligible positive base: C2 only (frozen C2 take-all, 16:15 exit; no new trigger passed PH3 / PH4 / PH6).  Checkpoint machinery = PH1.
(a) FRESH_SIGNAL_RECOVERY: ADD1 at the first independent bank event (C3, C5, C6, C7, C8) after entry while UNIT1 is underwater (close < entry).
    MATCHED CONTROL: underwater checkpoints without an independent event, same cells as PH1 (instrument x vt x TOD tercile x causal terciles of
    elapsed / unrealised P&L / remaining).  Primary: signal ADD1 minus matched ADD1 ($), date-clustered CI, folds, instruments; plus generic
    first-underwater ADD1 (blind averaging CONTROL; never a candidate).
(b) WINNER-PRESS STATE SPECIFICITY: generic first-winner ADD1 minus matched ALL-checkpoint ADD1 (same cells without the winner condition) —
    is adding specifically to a winning C2 trade better than adding at a random checkpoint of the same trade stage?
(c) Tails: worst basket day, basket MAE p95 / p99, 2022.
ADD2 eligibility (program sec. 41) for the winner-press arm: ADD1 base-cost EV > 0, SLIP4 EV > 0, >= 4/5 folds, n >= 150, matched state-specific
excess (b) > 0, worst basket not worse than 2 x worst single unit.  If eligible, ADD2 is preregistered separately (PH7B) before any ADD2 run;
otherwise ADD2 NOT_RUN_BY_RULE.  Recovery exits (basket BE, peel, resistance) only if (a) is positive with n >= 100; VWAP / AVWAP exits not
eligible (no validated family-specific VWAP value).
Classification per arm: SIGNAL_SPECIFIC / GENERIC (state value without signal) / NO_VALUE / STOP (marginal EV <= 0).
